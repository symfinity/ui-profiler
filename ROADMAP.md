## Details

### 0.1.x — Greenfield shell + stock collectors

UI Kernel and ux-blocks profiler layout, reskinned Symfony stock collectors, owned Sass pipeline, WDT and shell ES modules, Flex recipe, handbook spine, zero-legacy CSS gate

### 0.2.x — Split mirror + distribution

Packagist tag, split CI matrix, PHPUnit and PHPStan on public mirror, composer dev-deps parity, recipe publish, ui-lab smoke gate

### 0.3.x — WDT DOM bridge

Owned WDT templates, toolbar hydration and flyout parity, collector chip markup without stock classes, hostile CSS parity tests, ui-lab visual sign-off

### 0.4.x — Shell delegation wave 9

Further ux-blocks-core delegation, shell line-budget wave, shrink owned glue CSS, profiler-only hooks under data-ui-profiler attributes

### 0.5.x — Collector panel depth

Time, form, events, logger, and exception panel polish, sf-dump compat scope, panel script accessibility, extended collector parity manifest

### 0.6.x — Third-party collector DX

Bundle author handbook, data_collector and ui_profiler.menu cookbook, Twig override conventions, unmigrated panel policy, example collector

### 0.7.x — Kernel theme alignment

Ui-kernel collector panel depth, semantic colour and cascade layer readouts, settings theme picker parity, ui-designer preview hooks

### 0.8.x — Upstream sync + ecosystem

Symfony web-profiler upstream sync cadence, collector template drift checks, ecosystem bundle reskins, optional ux-runtime dual-interaction

### 0.9.x — Hardening

API freeze prep, CSS and JS performance budgets, accessibility audit, stock profiler migration guide, release candidate gate

### 1.0.x — Stable dev API

SemVer-stable configuration, collector override conventions, menu registry contract, long-term ui-kernel and ux-blocks-core compatibility
